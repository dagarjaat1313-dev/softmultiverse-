# SoftMultiverse

**One Universe. Infinite Software.**

A premium international software marketplace starter built with Next.js and TypeScript.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current scope

This repository contains the storefront UI and demo catalogue only. Product entries and prices are illustrative. Authentication, supplier integrations, verified license inventory, payment processing, tax handling, and automated license delivery must be configured and tested before accepting real orders.
